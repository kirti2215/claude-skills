# resume-ats-check

Check Kirti's resume against a job posting for ATS parsing problems and keyword coverage.

## When to use
- "Will this pass ATS?"
- You want a keyword match check before applying
- You're unsure if your formatting will parse correctly

## Example prompts
- `/resume-ats-check [paste resume] [paste JD]`
- `/resume-ats-check check my resume against this posting`

## What it produces
An ATS parsing assessment (formatting risks, section header issues) + keyword gap analysis showing which JD terms are missing from your resume.
