# jobfinder

Run Kirti's job search across four streams, match each job's responsibilities against her experience, and rank with sponsorship as a hard filter.

## When to use
- "Find me jobs"
- "Run my job search"
- You want a ranked list of roles with fit scores

## The four streams
1. Big companies (FAANG+, enterprise tech)
2. Startups (Series A–C)
3. Y Combinator early-stage outreach
4. Contract / advisory roles

## Example prompts
- `/jobfinder`
- `/jobfinder focus on PMM and strategy roles`
- `/jobfinder only startups this week`

## What it produces
A ranked list of roles with match reasoning, sponsorship filter applied, and outreach priority order.
