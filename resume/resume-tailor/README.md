# resume-tailor

Tailor Kirti's baseline resume to a specific job posting by changing emphasis and order, never facts.

## When to use
- You share a job description and want a version of your resume tuned to it
- You want to know which bullets to lead with for a specific role

## Example prompts
- `/resume-tailor [paste job description]`
- `/resume-tailor [JD] — this is a PMM role, weight the go-to-market experience`

## What it produces
A tailored version of your resume with reordered and re-emphasized bullets — no fabricated content, only reprioritization.
