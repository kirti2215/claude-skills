# resume-bullet-writer

Rewrite or audit Kirti's resume bullets so each shows a believable, defensible achievement.

## When to use
- "Fix my bullets"
- "Strengthen my resume"
- You want to audit whether bullets are achievement-oriented or just descriptive

## Example prompts
- `/resume-bullet-writer [paste bullets or full resume section]`
- `/resume-bullet-writer rewrite my Databricks experience section`

## What it produces
Rewritten bullets in the format: action verb + what you did + measurable outcome. Flags weak bullets and explains the fix.
