# llm-council

Run a decision, idea, or draft through a council of 5 advisors who answer independently, peer review each other anonymously, and end in a chairman verdict.

## When to use
- "Council this"
- "Run the council"
- "Pressure test this" or "debate this"
- You want multiple independent perspectives before making a call

## Example prompts
- `/llm-council should I write the next Strategy Lens article about Google's self-cannibalization problem?`
- `/llm-council here's my positioning for [role], is this the right angle?`
- `/llm-council [paste draft] — is this ready to publish?`

## What it produces
5 independent advisor takes → anonymous peer review round → chairman synthesis verdict.
