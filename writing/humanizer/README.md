# humanizer

Strips AI writing patterns from any text so it reads natural and human. For use on any writing: rewrites, drafts, emails, LinkedIn messages, posts, articles, and Claude's own replies.

## When to use
- Any piece of writing before it goes out
- "Does this sound like AI?"
- "Make this sound more like me"
- After Claude drafts something you plan to send or publish

## Example prompts
- `/humanizer [paste draft]`
- `/humanizer rewrite this email so it sounds less robotic`
- `/humanizer [paste LinkedIn post]`

## What it produces
A rewritten version with AI tells removed: no hedging phrases, no unnatural transitions, no over-structured formatting, no pattern-matched vocabulary.
