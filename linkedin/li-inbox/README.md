# li-inbox

Triage Kirti's LinkedIn inbox: sort pasted DMs and connection requests into categories and draft replies worth sending.

## When to use
- You paste your unread DMs or connection requests
- You want to know what's worth replying to and what to ignore
- You want reply drafts for the ones that matter

## Example prompts
- `/li-inbox [paste DMs]`

## What it produces
Messages sorted into: opportunities, recruiters, peers, asks, spam — with drafted replies for the ones worth responding to.
