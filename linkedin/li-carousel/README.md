# li-carousel

Write slide-by-slide copy for a LinkedIn document post (carousel) plus the post text above it.

## When to use
- You have a step-by-step, framework, or list idea that would be weak as a text post
- You want a carousel / document post
- The idea has clear visual stages

## Example prompts
- `/li-carousel the 5 questions to ask before any AI recommendation`
- `/li-carousel decision ladder: describe, challenge, specify, test, calibrate`

## What it produces
Slide-by-slide copy (title slide, content slides, CTA slide) + the LinkedIn post text to accompany it.
