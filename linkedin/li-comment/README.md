# li-comment

Write thoughtful comments on other people's LinkedIn posts using nine comment types.

## When to use
- You paste someone's post and want a comment
- You want an engagement round across several posts
- You want to add value to a conversation without posting yourself

## Example prompts
- `/li-comment [paste post]`
- `/li-comment [paste post] — make it a contrarian take`
- `/li-comment [paste post] — add a personal example`

## What it produces
A comment in your voice, using one of nine comment types (add insight, share experience, ask a question, etc.).
