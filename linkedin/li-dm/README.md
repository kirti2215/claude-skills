# li-dm

Write LinkedIn connection notes and DM follow-ups that get replies: the 200-character invite, first message, and two follow-ups.

## When to use
- You're reaching out to a specific person on LinkedIn
- You want a connection request note + a follow-up sequence

## Example prompts
- `/li-dm [name], [their role/company], [why you're reaching out]`
- `/li-dm reaching out to a VP of Analytics at a fintech I want to work at`

## What it produces
A 200-character connection note + first message + two follow-ups, all in your voice.
